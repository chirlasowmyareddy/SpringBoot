@Controller - It indicates that the class is responsible for handling incoming HTTP requests
@RestController - Controller + Response Body
@ResponseBody - tells the return type of the method should be considered as the http response
@ResponseMapping - which exactly does the mapping of the API
    eg: @ResponseMapping(path = "/v1/card" , method = RequestMethod.GET)
    at class level also eg: @ResponseMapping(value = "/api") .can write common paths in the class level itself
@GetMapping(path = "/v1/card")  - simplifies
@PostMapping
@RequestParam - used to bind,request parameter to controller method parameter.generally it would be by default as true
/api/fetchUser?firstName=SOWMYA&lastName=
-
The framework automatically performs type conversion from the request parameter's string representation to the specified type
primitve types-such as int,long,float,double,boolean etc
wrapper classes- Such as Integer,Long,Float,Double,Boolean etc
string-request parameters are inherently treated as strings only
enums-you can bind request parameters to enum types
Custom object types-we can do it using a registered PropertyEditor

@PathVariable-used to extract values from the path of teh URL and help to bind it to controller method parameter
@RequestBody-bind the body of http request(typically json) to controller method parameter(java object)
@JsonProperty
